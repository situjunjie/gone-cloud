# 工作项自定义字段与动态筛选

## Goal

为项目工作项提供项目级自定义字段能力，使项目管理员能够按业务需要创建字段、维护选择项，并让工作项创建、修改、详情、列表和查询视图完整支持这些字段。

典型场景是为 `REQUIREMENT` 工作项增加“需求类型”单选字段，并由不同项目分别维护“产品类需求”“技术类需求”等选项。

## Requirements

### 字段配置

- 自定义字段归属于一个具体项目，不在项目之间共享实际字段定义或字段值。
- 字段具有不可变的项目内唯一编码、名称、字段类型、适用工作项分类、是否必填、启用状态和排序。
- 首期支持 `TEXT`、`NUMBER`、`DATE_TIME`、`SINGLE_SELECT`、`MULTI_SELECT`、`USER`、`BOOLEAN` 类型。
- 字段编码和字段类型创建后不可修改，防止已有值、筛选条件和查询视图失效。
- 字段只能禁用，首期不提供物理删除或逻辑删除入口；禁用后不允许新写入，但历史值仍可展示和筛选。
- 字段可以限定适用于某一个工作项分类；未指定分类时适用于项目内全部工作项。
- 项目管理员可以创建、修改、启用和禁用字段，并查询项目可用字段列表。

### 选项配置

- 单选和多选字段支持项目内自定义选项。
- 选项具有不可变编码、显示名称、颜色、启用状态和排序。
- 选项只能禁用；禁用后不允许新写入，但历史工作项及已有查询视图仍能解析其名称。
- 非选择类型字段不允许维护选项。

### 工作项赋值与回显

- 创建和完整更新工作项时可以同时提交自定义字段值，并与工作项主记录处于同一事务。
- 快捷字段更新接口支持通过 `custom:<fieldId>` 更新自定义字段。
- 必填校验、字段适用分类、字段所属项目、字段类型、选项归属和选项状态均由后端校验。
- 修改工作项分类时，若已有自定义字段不再适用于新分类，则拒绝修改并给出业务错误，不静默丢弃数据。
- 修改工作项所属项目时，如果工作项已有自定义字段值，则拒绝迁移；首期不做字段映射或自动清理。
- 工作项详情和分页结果返回字段元数据及类型化字段值。
- 分页回显必须批量加载当前页字段值，不能产生逐工作项查询的 N+1 问题。
- 删除工作项时，其自定义字段值随业务操作一并删除。

### 动态筛选

- 保留现有固定字段查询协议，并支持 `custom:<fieldId>` 字段编码。
- 自定义字段筛选必须指定单一 `projectId`，首期不支持跨项目自定义字段筛选。
- 根据字段类型限制可用操作符：
  - 文本：`eq`、`ne`、`contains`、`not_contains`、`is_empty`、`is_not_empty`
  - 数字和日期：`eq`、`ne`、`gt`、`ge`、`lt`、`le`、`between`、`is_empty`、`is_not_empty`
  - 单选、多选和用户：`eq`、`ne`、`in`、`not_in`、`contains`、`not_contains`、`is_empty`、`is_not_empty`
  - 布尔：`eq`、`ne`、`is_empty`、`is_not_empty`
- 正向匹配通过 `EXISTS` 实现，反向匹配通过 `NOT EXISTS` 实现，避免多选值导致分页重复。
- `ne`、`not_in`、`not_contains` 只表达“不包含指定值”；空值查询必须显式使用 `is_empty`。
- 服务端必须校验字段归属、适用分类、操作符、值类型和选择项归属，禁止将客户端字段字符串直接拼接为 SQL。
- 每次查询最多允许 20 个动态条件。

### 查询视图兼容

- 现有查询视图 `condition_json` 和列配置可以保存 `custom:<fieldId>`。
- 字段或选项禁用后，已有查询视图仍可以读取；执行时允许使用禁用字段和选项查询历史数据。
- 字段元数据接口需要返回前端构建筛选器和动态列所需的信息。

## Constraints

- `ProjectWorkItemDO` 保持核心稳定字段，不增加 `Map<String, Object>` 或 JSON 自定义字段列。
- 自定义字段值使用类型化关系模型，不能把所有值统一存为字符串。
- 所有新增业务表遵循租户隔离和标准审计字段约定。
- 首期仅维护 MySQL 中已经存在的 `project.sql` 对象；若后续项目模块增加其他数据库脚本，需要同步迁移。
- 首期不支持租户级字段模板、字段继承、项目间字段复制、字段类型迁移、计算字段和字段级权限。

## Acceptance Criteria

- [x] 项目管理员可以创建七种首期字段，并能修改名称、适用分类、必填、启用状态和排序。
- [x] 项目管理员可以维护单选和多选字段的项目级选项，并安全禁用字段或选项。
- [x] 同一项目字段编码唯一，不同项目可以使用相同编码并维护不同选项。
- [x] 工作项创建、完整更新、快捷更新、删除均正确处理自定义字段值和事务。
- [x] 工作项详情与分页响应包含正确的自定义字段元数据和值，分页无 N+1 查询。
- [x] 必填、类型、项目、分类、用户和选项校验均有明确业务错误。
- [x] 固定字段筛选保持兼容，自定义字段支持类型对应的操作符及空值筛选。
- [x] 多选字段筛选不会造成工作项重复，反向筛选和空值筛选语义有测试覆盖。
- [x] 查询视图可以保存并执行自定义字段条件及列配置。
- [x] 字段或选项禁用后历史工作项仍可回显和筛选，禁用对象不能用于新写入。
- [x] 受影响模块的编译和聚焦测试通过。
