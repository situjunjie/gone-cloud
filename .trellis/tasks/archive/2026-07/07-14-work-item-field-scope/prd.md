# 工作项字段支持全局与项目作用域

## Goal

让工作项自定义字段定义具有明确的生效范围：全局字段可被范围内所有项目使用，项目字段只对指定项目生效；工作项赋值、必填校验、回显和动态筛选必须遵守同一套作用域规则。

## Background

- 当前 `WorkItemFieldDO.projectId` 和 `proj_work_item_field.project_id` 均为必填，字段定义只能归属单一项目。
- 当前字段列表、字段编码唯一性、字段值写入校验、必填校验和动态筛选都以 `field.projectId == workItem.projectId` 为前提。
- 已归档的“工作项自定义字段与动态筛选”设计曾明确排除租户级字段模板；本任务依据新的产品需求替换该限制，同时保持现有项目字段兼容。
- 字段值和查询视图使用稳定 `fieldId`，因此作用域扩展不能重建已有字段或改变已有字段编号。

## Requirements

### 作用域模型

- 持久化字段定义必须显式保存 `GLOBAL` 或 `PROJECT` 作用域，不能只依赖 `projectId` 推断。
- `PROJECT` 字段必须绑定一个有效且可用的项目；`GLOBAL` 字段不绑定具体项目。
- 现有字段数据迁移后全部保持为 `PROJECT` 作用域，原有字段编号、选项、字段值和查询视图引用保持不变。
- 字段作用域、所属项目、编码和字段类型创建后不可修改，避免已有值和查询条件改变含义。
- `GLOBAL` 严格表示当前租户内所有项目生效，继续受 `TenantBaseDO` 和租户插件隔离，不跨租户共享。

### 字段管理

- 字段创建、更新、启停、列表和响应 DTO 必须包含作用域信息。
- 查询某个项目的可用字段时，返回生效的全局字段和该项目字段，并保持稳定排序。
- 选择项继承字段定义的作用域，不单独声明作用域；全局选择字段的选项对所有生效项目一致。
- 项目字段不允许覆盖全局字段；任一项目的最终生效字段集合中 `code` 必须唯一。
- 创建项目字段时，其 `code` 不得与当前租户的全局字段重复；创建全局字段时，只要当前租户任一项目已有同 `code` 字段就拒绝创建。
- 不同项目之间仍允许存在相同 `code` 的项目字段。
- 全局字段管理使用独立权限 `project:work-item-field:global-manage`，覆盖全局字段及其选项的创建、修改和启停；租户管理员默认拥有该权限，也允许授权给其他角色。
- 全局和项目字段读取继续使用 `project:work-item:query`；项目字段管理继续使用 `project:work-item:update`。
- 全局字段管理与项目字段管理使用明确分离的写接口，服务端不得只信任客户端提交的作用域决定权限。

### 工作项写入与读取

- 创建、完整更新和快捷更新工作项时，允许写入对当前项目生效的全局字段和本项目字段。
- 其他项目的项目字段仍必须被拒绝。
- 必填校验必须同时考虑启用的全局必填字段和当前项目必填字段，并继续遵守适用工作项分类。
- 新增全局必填字段后采用存量延迟补齐：新建工作项立即必填；存量工作项查询和仅修改核心字段不受影响；一旦提交完整自定义字段快照或快捷修改任意自定义字段，就必须补齐当前生效的全部必填字段。
- 字段值继续使用既有类型化表和稳定 `fieldId`，不复制全局字段定义或字段值到项目。
- 工作项详情和分页回显继续批量加载字段元数据和值，不引入 N+1 查询。

### 动态筛选与查询视图

- `custom:<fieldId>` 查询条件对全局字段和当前项目字段均有效。
- 项目字段只能用于其所属项目的查询；全局字段可以用于范围内任一单项目查询。
- 当前“自定义字段筛选必须指定单一 `projectId`”的边界保持不变，本任务不扩展跨项目动态筛选。
- 既有查询视图中的项目字段编号保持可执行；新查询视图可以保存全局字段编号。

### 兼容与质量

- 现有字段创建调用方需要有明确的兼容策略，不能因新增作用域字段静默创建错误范围的字段。
- 更新 MySQL `project.sql` 中字段表结构、唯一索引和查询索引；其他数据库当前未维护该对象，不新增孤立对象。
- 增加字段作用域管理、合并列表、字段值校验、必填校验和动态筛选的聚焦测试。

## Out of Scope

- 跨租户共享字段。
- 将全局字段复制为项目字段或在项目间复制字段。
- 项目级修改全局字段定义或全局选项。
- 跨项目自定义字段筛选、排序、分组和统计。

## Acceptance Criteria

- [x] 可以创建、修改、启停并查询 `GLOBAL` 与 `PROJECT` 两类字段定义。
- [x] 现有字段无损迁移为 `PROJECT`，已有字段值和查询视图引用不变。
- [x] 项目字段列表正确合并生效的全局字段与当前项目字段。
- [x] 工作项创建、完整更新和快捷更新正确接受生效字段并拒绝越界项目字段。
- [x] 全局与项目必填字段均按启用状态和适用分类校验。
- [x] 全局和项目字段均支持现有七种类型、选项、回显和动态筛选。
- [x] 字段编码唯一性与覆盖规则在 API、服务校验和数据库唯一索引中保持一致。
- [x] 全局字段管理具备不会被普通项目编辑权限越权调用的权限边界。
- [x] 受影响模块编译通过，聚焦单元测试通过。
