# 工作项查询支持 AND 条件组与组间 OR

## Goal

让工作项分页查询支持由多个条件组组成的过滤表达式：每个条件组内部固定使用 `AND`，条件组之间固定使用 `OR`。工作项查询视图必须保存、读取并校验同一份条件组结构，使视图回放与直接分页查询保持一致。

## Background

- 当前 `/project/work-item/page` 已支持普通字段和 `custom:<fieldId>` 自定义字段的结构化条件。
- 当前 `conditions` 是扁平列表，Mapper 逐条追加条件，因此所有条件固定为 `AND`。
- 当前查询视图的 `condition_json` 可以保存扁平条件，但创建和更新视图时不会复用分页查询的字段、操作符、项目边界和选项校验。
- 既有 `07-05-project-workitem-query-logic` 任务已完成扁平字段逻辑查询，本任务只扩展条件分组及视图一致性。

## Requirements

### 条件组合模型

- 新增 `conditionGroups` 查询结构，每个组包含一个非空 `conditions` 列表。
- 单个组内所有条件固定使用 `AND`。
- 多个条件组之间固定使用 `OR`。
- 不支持条件组继续嵌套，也不允许客户端提交任意逻辑运算符。
- 同一个普通字段或自定义字段可以出现在不同条件组中。
- 顶层固定过滤参数，例如 `projectId`、`keyword`、`status`，继续与完整条件组表达式使用 `AND` 连接。
- 整体语义示例：`projectId = P AND ((A = a AND C = c) OR (A = b AND B = a))`。

### 字段与操作符

- 条件组内继续支持现有普通字段、当前租户全局工作项字段和当前项目工作项字段。
- 沿用现有字段类型、操作符、值解析、`me/currentUser/self` 用户令牌和选择项校验规则。
- 自定义字段查询仍要求指定单一 `projectId`，不扩展跨项目查询。
- 单个条件组不能为空，全部条件总数不能超过现有上限 20 条。
- 无条件组时不附加分组表达式；空组、超过上限或无效条件必须在构建 SQL 前失败。

### 兼容策略

- 保留现有扁平 `conditions` 请求字段，继续解释为一个组内全 `AND` 的条件集合。
- 新请求优先使用 `conditionGroups`。
- 同一次请求不能同时提交非空 `conditions` 和非空 `conditionGroups`，避免产生隐式组合语义。
- 现有只保存 `conditions` 的查询视图必须可以继续读取和回放，无需数据库迁移。

### 查询视图

- `WorkItemQueryViewDO.QueryCondition` 增加与分页请求一致的 `conditionGroups` 结构。
- 查询视图创建和更新时必须校验条件组结构、字段、操作符、值格式、自定义字段项目边界和选择项归属。
- 视图保存校验不能把 `me/currentUser/self` 替换成当前用户编号；令牌必须原样保存，在实际分页执行时再解析。
- 视图读取必须完整返回条件组结构，不丢失字段、操作符、单值、区间值或多值。
- 本任务不增加通过 `viewId` 或 `viewCode` 直接执行分页查询的服务端入口；调用方仍先读取视图，再提交其中的查询条件。
- `config.sorts`、`config.groupBy` 等展示配置的实际执行不在本任务范围内。

### SQL 与安全

- SQL 必须生成明确括号，使组内为 `AND`、组间为 `OR`，且整个分组表达式与顶层固定过滤条件使用 `AND`。
- 自定义字段条件继续使用服务端解析的字段元数据、固定物理列映射和绑定参数。
- 多值自定义字段继续使用相关子查询，不能通过 JOIN 导致分页主记录重复。
- 不允许客户端值直接决定 SQL 列名、逻辑运算符或 SQL 片段。

## Out of Scope

- 任意深度的布尔表达式树。
- 组内 `OR` 或组间 `AND` 的自定义切换。
- 跨项目自定义字段查询。
- 查询视图排序、分组和统计的后端执行。
- 前端条件构建器和视图页面实现。

## Acceptance Criteria

- [x] 分页接口可执行 `(A AND C) OR (A AND B)` 形式的条件组表达式。
- [x] 条件组内只生成 `AND`，组间只生成 `OR`，并与顶层固定过滤条件使用 `AND`。
- [x] 条件组可以混合普通字段、租户全局字段和当前项目字段。
- [x] 扁平 `conditions` 调用保持原有全 `AND` 行为。
- [x] 同时提交两种条件格式、空组、超过 20 条或无效条件时返回明确业务错误。
- [x] 查询视图可无损保存和返回 `conditionGroups`，旧扁平视图继续可用。
- [x] 查询视图创建和更新会提前拒绝无效字段、操作符、值、选项和越界自定义字段。
- [x] 查询视图保存后仍保留 `me/currentUser/self` 令牌，实际分页时按当前登录用户解析。
- [x] Mapper 聚焦测试验证括号、组内 AND、组间 OR、顶层 AND 和自定义字段相关子查询。
- [x] 受影响模块编译通过，分页查询与查询视图聚焦测试通过。
